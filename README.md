# 文本去重改进脚本

## 问题描述

原始脚本存在重复项检测不完整的问题，即使经过去重处理，仍然会有相同的文本在输出文件中出现多次。

## 根本原因

原脚本的去重问题主要由以下因素造成：

1. **不充分的空白字符标准化**
   - 不同的空格、制表符、换行符组合导致相同文本被识别为不同内容
   - 中文文本中的全角空格和半角空格混用

2. **缺少Unicode标准化**
   - 中文字符可能有不同的Unicode表示形式（如"号"可能是`\u53f7`或其他变体）
   - 全角/半角字符混用（如"！"vs"!"）

3. **正则表达式不完整**
   - 引用内容可能跨多行，但原正则未使用`DOTALL`标志
   - 某些特殊字符（零宽字符）未被移除

4. **缺少后处理验证**
   - 没有验证去重效果的机制
   - 无法追踪哪些内容被识别为重复

## 改进方案

### 主脚本：`clean_duplicates_improved.py`

#### 关键改进：

1. **Unicode标准化 (NFKC)**
   ```python
   text = unicodedata.normalize('NFKC', text)
   ```
   - 将所有Unicode变体统一为标准形式
   - 处理全角/半角字符转换
   - 确保相同字符使用相同编码

2. **增强的空白字符处理**
   ```python
   text = re.sub(r'\s+', ' ', text)
   ```
   - 将所有类型的空白字符（空格、制表符、换行符等）统一为单个空格
   - 移除首尾空白
   - 确保文本标准化

3. **零宽字符移除**
   ```python
   text = re.sub(r'[\u200b-\u200f\u202a-\u202e\ufeff]', '', text)
   ```
   - 移除不可见字符（零宽空格、左右标记等）
   - 这些字符常导致看似相同的文本实际不同

4. **多行模式正则**
   ```python
   text = re.sub(r'引用.*?".*?"', '', text, flags=re.DOTALL)
   ```
   - 使用`re.DOTALL`确保`.`匹配包括换行符
   - 正确处理跨行的引用内容

5. **过短文本过滤**
   ```python
   df = df[df['清洗后文本'].str.len() >= min_length]
   ```
   - 移除清洗后少于10字符的文本
   - 减少噪音数据

6. **详细的重复项日志**
   - 生成`duplicates_removed.txt`记录所有被移除的重复项
   - 包含每组重复的完整文本
   - 便于验证去重逻辑

7. **处理进度显示**
   - 实时显示处理进度
   - 统计各阶段移除的记录数
   - 最终汇总报告

### 辅助脚本：`find_duplicates.py`

用于分析和发现残留的重复项，提供两种检测模式：

1. **完全重复检测**
   - 找出所有完全相同的文本
   - 列出每组重复的所有行号
   - 显示原始文本进行对比

2. **模糊相似度检测**
   - 使用`SequenceMatcher`计算文本相似度
   - 默认阈值95%（可调整）
   - 显示字符级差异分析

3. **详细报告生成**
   - 生成`remaining_duplicates_report.txt`
   - 包含每对重复/相似文本的详细对比
   - 标注具体差异位置

## 使用方法

### 1. 运行改进的去重脚本

```bash
python clean_duplicates_improved.py
```

**输出文件：**
- `cleaned_YYYY.txt` - 按年份分类的清洗文本
- `summary_statistics.csv` - 统计摘要
- `duplicates_removed.txt` - 被移除的重复项日志

### 2. 验证去重效果（可选）

```bash
python find_duplicates.py
```

**输出文件：**
- `remaining_duplicates_report.txt` - 残留重复项分析报告

### 3. 调整参数（如需要）

在脚本中可以调整的参数：

**`clean_duplicates_improved.py`：**
```python
min_length = 10  # 最小文本长度（字符数）
```

**`find_duplicates.py`：**
```python
SIMILARITY_THRESHOLD = 0.95  # 相似度阈值 (0.0-1.0)
sample_size = 5000  # 检查的记录数（大数据集时调整）
```

## 疑难排查

### 如果仍然发现重复项：

1. **运行验证脚本**
   ```bash
   python find_duplicates.py
   ```

2. **检查报告**
   - 查看`remaining_duplicates_report.txt`
   - 确认是完全重复还是高度相似

3. **分析差异**
   - 报告会显示字符级差异
   - 可能需要调整清洗逻辑

4. **调整参数**
   - 如果是高度相似（非完全重复），考虑使用模糊匹配
   - 降低`SIMILARITY_THRESHOLD`可以找到更多相似文本

### 性能优化：

对于大型数据集（>100,000条）：

1. **调整验证脚本采样大小**
   ```python
   sample_size = min(len(df), 1000)  # 减少到1000
   ```

2. **分批处理**
   - 按年份或其他字段分批运行
   - 减少内存占用

3. **使用哈希加速**（高级）
   - 可以添加文本哈希进行预筛选
   - 只对哈希相同的文本进行详细比较
